# OpenRadar real NOAA MRMS preview

These are real NOAA MRMS GRIB2 radar observations of the May 21, 2024 Greenfield, Iowa storm, plus intermediate frames generated by the numeric motion engine. Observed scans are marked separately from model estimates. **This is not a realtime forecast, and not model certification.**

Metadata and original NOAA S3 source URLs and SHA-256s are in `greenfield-2024-provenance.json`. GIF and MP4 are identical-source videos.
