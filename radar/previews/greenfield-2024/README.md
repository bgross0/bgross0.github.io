# Real NOAA MRMS Greenfield radar animation

[Watch the animated GIF](./greenfield-2024-real-noaa.gif)

This GIF contains seven real NOAA MRMS GRIB2 observations from May 21, 2024 near Greenfield, Iowa and eighteen **estimated/interpolated** intermediate frames. It compares observed frame stepping, numeric crossfade and PySTEPS-LK motion estimation. Sources, model settings and original NOAA archive file SHA-256 hashes are in `greenfield-2024-provenance.json`.

**Important:** This is a retrospective comparison, not a real-time forecast or certified severe-weather prediction.
